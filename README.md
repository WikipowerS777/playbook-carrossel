## Como instalar no seu Claude (5 minutos, sem programar)

**Jeito mais fácil:** abra uma conversa nova no Claude e cole:

```
Acesse este repositório do GitHub e leia o README: https://github.com/WikipowerS777/playbook-carrossel
Depois me guie para instalar o playbook de carrossel no meu Claude e criar o meu primeiro carrossel.
```

**Jeito fixo (recomendado), num Projeto do Claude:**
1. No claude.ai, clique em **Projetos** e crie um projeto chamado "Carrossel".
2. Em **Instruções do projeto**, cole todo o conteúdo de `INSTRUCOES-DO-PROJETO.md`.
3. Em **Conhecimento do projeto**, anexe `PLAYBOOK.md`, `PORTAO.md`, `ESTRATEGIA.md` e o seu `MEU-PERFIL.md` preenchido.
4. Abra uma conversa dentro do projeto e peça: **"Monta o meu primeiro carrossel."**

Pronto. Toda conversa dentro desse projeto já sabe as leis, os moldes e o seu jeito.

**Se você usa o Claude Code** (terminal ou VS Code): clone o repositório e peça "leia o README e trabalhe como o squad de carrossel".

## Como ele trabalha

1. **Pesquisa:** pergunta o tema ou busca o que está em alta no seu nicho.
2. **Estratégia:** responde as 6 perguntas do post (objetivo, valor, o que ele semeia, prova, objeção, consciência).
3. **Roteiro:** escolhe um dos 9 moldes e escreve slide por slide, mais legenda e palavra-código.
4. **Portão:** confere contra as leis. Capa fraca, slide vazio ou objeção aberta voltam para reescrever.
5. **Você aprova** e posta.
6. **Placar:** 72 horas depois, você cola os números e ele registra o que aprendeu para o próximo.

Cada volta deixa o seu squad mais inteligente.
